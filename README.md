# 本地AI对话工作台

本地运行的 AI 聊天工作台：**角色扮演**和**直连对话**两套模式，数据只存在你自己的机器上。
零 npm 依赖，只要一个 Node.js（没有的话可以一键下载便携版）。

- 🎭 **角色卡**：人设 / 背景 / 开场白 / 一句话简介 / 常用词，随时二次编辑，不打断当前对话
- ⌨️ **输入框敲 `/`**：选「以对话里谁的身份发这条消息」（多人卡里换个身份说话，只对下一条生效；发了就换回来）
- ✨ **星野角色抓取**：粘贴星野分享链接 / 整段分享文案，自动抓取角色设定、开场白、示例对话与头像并注册成角色；也能按关键词搜索星野角色、管理已抓取的角色
- 💬 **直连模式**：不带任何系统提示词，你打什么就发什么；想加点说话习惯可以单独配一组口头禅
- 🧠 **资料库**：一份共享资料（直连 + 所有角色都读）+ 每个角色各自一份，支持关键词检索和语义检索（本地 embedding 缓存）
- 🌐 **联网搜索**：每轮先用必应搜一次，结果只作参考资料注入系统提示词，不写进聊天记录
- 📷 **识图 / 附图**：交给本机 Ollama 的视觉模型描述画面，图片不出本机
- 🔊 **朗读**：接任意 OpenAI 兼容的 `/v1/audio/speech` 服务，把角色台词读出来
- ⚡ 流式输出、多轮记忆、历史会话管理
- 🧹 回复质量控制：自动清掉凭空造出来的动静、动作开头、发送前清洗套路、字数上限、撤回 / 重新生成 / 已否决
- ⏰ **工作时段锁**：工作日上班时间禁止发消息（只对云端接口生效，本地 / 内网不受限）
- 🖥 **本机 Ollama 管理**：启动 / 预加载 / 常驻显存 / 立刻释放 / 一键切模型 / 关掉思考
- 📱 局域网内手机 / 平板用浏览器直接打开；也能在安卓 Termux 上独立运行
- 🔒 数据、API Key 全部存在本机，无遥测、无账号、无云端

## 环境要求

- **Node.js 18+**（推荐 LTS）。不想自己装也行：
  - Linux / macOS：`bash linux/get-node.sh`
  - Windows：双击 `windows\start.cmd`，检测不到 Node 时会自动下载便携版
  便携版只解压到项目的 `runtime/` 目录，**不写系统路径、不需要管理员权限**。
- 想用本地模型：另装 [Ollama](https://ollama.com/)（可选，纯云端 API 不需要）
- 想联网搜索 / 朗读 / 识图：都是可选功能，不配就不启用

## 快速开始

启动后浏览器打开 <http://127.0.0.1:5178>，首次使用点右上角 **⚙ 设置**填 API Key。

### Windows

```
windows\start.cmd                    双击启动（默认 5178，只监听本机）
windows\start.cmd 5179               换端口
windows\start.cmd 5178 0.0.0.0       同 Wi-Fi 的手机 / 平板也能连
windows\start-minimized.cmd          最小化启动，可做开机自启
windows\stop.cmd                     结束 node.exe
```

想开机自启：给 `start-minimized.cmd` 建个快捷方式，丢进 `shell:startup` 文件夹。

```bash
bash linux/setup.sh     # 一次性：检查（或下载）Node、装 workbench 命令
bash linux/run.sh       # 启动，默认 5178；会自动开浏览器
```

之后在任何目录敲 `workbench` 就能启动（`workbench 5178 0.0.0.0` 可让手机连）。

### macOS

```bash
bash linux/get-node.sh   # 可选：装便携 Node
bash linux/run.sh
```

不需要电脑。从 F-Droid 装 Termux，然后把传输包传进手机解压：

### 手机 / 平板浏览器直接连电脑

电脑上换成监听全部网卡：`node start.js 5178 0.0.0.0`（或 `workbench 5178 0.0.0.0`），
启动横幅会把本机所有可用 IP 列出来，手机连同一个 Wi-Fi 打开对应地址即可。

## 本地模型（Ollama）

装了 Ollama 就能完全离线跑（`ollama pull qwen3:8b` 之类）。设置里点一下模型列表里的
「用这个」，会**一次把 Base URL / Key / 模型名 配好**（「关掉思考」不会自动改）。

几个实用点：

- **上下文与显存**：模型窗口（`num_ctx`）越大越吃显存，8 GB 卡建议 8K 以内。
- **关掉思考**：Qwen3 这代不关思考会先写一大段推理，慢很多。**需要手动勾选**，切模型时不会自动开。
- **常驻**：默认用完几分钟卸载；点 📌 可让它常驻显存，🧹 立刻还给显卡。
- **模型目录不对**：如果 Ollama 里看不到你导入的模型，多半是启动时没带 `OLLAMA_MODELS`；
  可以设环境变量 `OLLAMA_EXE` / `OLLAMA_MODELS` 告诉工作台它们在哪。

### 让别的设备用这台电脑的 Ollama

Ollama 默认只监听 `127.0.0.1`，别的设备连不上。两种做法：

**A. 改监听（简单，但会把端口开放给同网络）**

```bash
# Linux（systemd）
sudo systemctl edit ollama     # 加：[Service]  Environment="OLLAMA_HOST=0.0.0.0:11434"
sudo systemctl daemon-reload && sudo systemctl restart ollama
# 临时
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

Windows：用户环境变量加 `OLLAMA_HOST=0.0.0.0`，退出托盘里的 Ollama 再启动，防火墙放行 11434。
别的设备上把 Base URL 填 `http://<这台电脑的IP>:11434/v1`、Key 留空即可。

**B. SSH 隧道（推荐，不用改对方配置、也不暴露给局域网）**

```bash
ssh -N -L 11434:127.0.0.1:11434 用户名@那台电脑
```

然后本机 Base URL 填 `http://127.0.0.1:11434/v1` —— 对工作台来说这就是「本机 Ollama」，
**模型列表、一键切模型、附图、识图全都能用**。

> ⚠ 用别人电脑上的 Ollama 时：🧹 释放显存 / 📌 不关闭 会真的作用到对方那台机器；
> 对方没在用时模型是冷的，第一条消息会慢十几秒；你们还会抢同一块显卡。
> 另外 11434 没有鉴权，开放出去意味着同网络的人都能用你的显卡、还能拉取/删除模型。

## 角色扮演的用法

### 角色卡

左侧「角色」→ **+ 新建角色**：名字、人设、背景、开场白、一句话简介、常用词。
点角色进入聊天，开场白会先以预览样式显示，你发第一条消息后它就成为对话的一部分。
角色卡随时可以 **✎ 编辑**，改完立即生效，不会打断正在进行的对话。

### 常用词 / 等义词

- **常用词**：每个角色可以配一组口头禅和出现频率，会写进提示词，说话更像本人。
- **等义词**：设置里的全局对照表，写「我这么说 = 我什么意思」，梗、俗称、黑话都能教给它；
  行尾加 `#输出` 表示回答时也用这个说法。

### 维度与特点提示词

每个角色有一份**维度图**（动作 / 神态 / 语言 / 反应 / 环境 / 主动性 / 常用词…），
分数越高这方面越突出，**语言 0 = 那一轮不写台词**。没单独设过的角色用设置里的默认值。
角色的 **🎛 维度** 里还能填一段「特点提示词」，只对这一轮 / 这个角色生效。

### 叙事推进 / 场景备忘

- **叙事推进指令**：写进系统提示词，让角色主动推进剧情而不是只回应上一句。**默认不注入**——要开就在设置里自己写一段；清空即关闭。
- **场景备忘**：记下「现在在干什么」，治模型聊久了忘记场景的毛病。

### 直连模式

左侧「直连」→ **+ 新对话**：**一条系统提示词都不发**，也不做任何后处理，你打什么就发什么。
想让它带点说话习惯，用右上角 💬 常用语（这是唯一会注入的一段，不填就一个字都不加）。

## 星野角色抓取（✨ 星野）

左侧「星野」标签页：把星野 App 里的**分享链接**（或整段分享文案，中文、表情、换行都能直接粘）丢进去，
工作台会自动解析 `npc_id` → 抓取角色设定 / 开场白 / 示例对话 / 头像 → 转成角色卡并**自动注册**到「角色」列表。

- **批量粘贴**：一次粘多条分享消息（一行一条也行），抓取过程有进度和日志；同一任务只允许一个，避免把接口打爆。
- **自动注册**：默认抓完就注册；重复的 `npc_id`、本地已有同名角色会自动跳过，不产生重复角色。
- **搜索**：顶部搜索框可以直接搜星野角色（名字 / 标签），搜索结果点「注册」会先抓完整角色卡再注册。
- **已抓角色管理**：下面列出所有抓取过的角色，可筛选、看详情（设定 / 开场白 / 场景）、重新注册、移除抓取记录。
  「移除」只删本地保存的抓取记录（角色卡 + 头像），**不会删除已经注册的角色，也不影响已有会话**。
- **数据在哪**：`<数据目录>/xingye/` —— `registry.json`（索引）、`cards/<npcId>.json`（完整角色卡）、
  `avatars/<npcId>.<ext>`（头像原图）；抓取记录和角色卡都是本地文件，不上传。

> 抓取的是星野公开角色资料，仅供个人研究 / 角色卡迁移；请求有频率控制（每个角色间隔 0.3~0.5 秒）。
> 如果网络不通或接口变动，面板会给出明确报错，不影响工作台其它功能。

## 回复质量控制

| 开关 | 作用 |
| --- | --- |
| 自动清掉「凭空造出来的动静」 | 模型爱自己加「门外的脚步声」这类场景里没有的事来打断剧情；勾上后在**写进聊天记录之前**删掉 |
| 动作开头 | 给回复塞一个 `*角色名` 的开头，逼角色先动再说话，堵掉「你来了就好」式回避 |
| 发送前清洗历史里的套路 | **只改发出去的上下文**，聊天记录一个字不动（👁 能看到实际发出去的样子） |
| 字数上限 | 超了就截断，截掉的部分进「已否决」备查 |

回复不满意可以在气泡上用**撤回 / 重新生成 / 已否决**；重新生成会把上一版放进「已否决」，
方便对比换哪个走向更好。

## 资料库与语义检索

聊天页 **📚** 的资料库分两层：

| 层 | 谁能读到 | 存在哪 |
| --- | --- | --- |
| **共享资料** | **直连模式 + 所有角色** | `data/knowledge/_shared.md` |
| **这个角色的资料** | 只有当前角色 | `data/knowledge/<角色id>.md` |

角色模式实际注入的是「共享 + 这个角色」两份拼起来的内容；直连模式只读共享那份。
纯文本、空行分块，检索支持两种：

- **关键词检索**：默认，够快够稳
- **语义检索**：按意思找资料，需要配一个 embedding 接口；算过的向量会缓存在本地，下次直接复用

> 从旧版本升级：直连模式原来那份 `_direct.md` 会在第一次读取时自动改名成 `_shared.md`，内容不丢。

## 联网搜索（必应）

设置 →「联网搜索」：默认关着，聊天页 **🌐** 随时开关。

- **站点**：国际版 `www.bing.com`（一般要代理）/ 国内版 `cn.bing.com`（可直连）
- **取几条 / 注入上限**：控制参考资料的长度，免得挤掉聊天上下文
- 搜索结果只进系统提示词的参考层，**不改写你说的话、不进聊天记录**；关着时一次网络请求都不发
- 必应按**出口 IP** 决定给哪个版本：选了国际版又没走代理会被重定向到国内版，真发生时会提示你
- 搜索词取你这一轮说的话（自动剥掉 `*动作*` 和 `（环境）`）

## 朗读

设置 →「朗读」填任意实现了 `POST /v1/audio/speech` 的服务地址（GPT-SoVITS 的 OpenAI 封装、
openedai-speech、Kokoro-FastAPI 等），再选模型 / 音色 / 语速 / 格式，点「试听」试一句。
每个角色还能单独指定音色。聊天页 🔇/🔊 控制自动朗读，**音频不出本机**。

## 识图 / 附图

两个按钮都在输入框左边，都需要**本机 Ollama + 视觉模型**（默认
`qwen2.5vl:3b`，可在设置里改）：

- **📷 识图**：选一张图，让视觉模型描述画面里在发生什么，描述文本会填进输入框
- **🖼 附图**：把图直接发给角色看（这一轮临时切到视觉模型，图片不进聊天记录，历史里存的仍是纯文本）

## 工作时段锁

工作日 **09:00–12:00、14:00–18:00（北京时间）** 由**服务端**直接拦截对话，其余时间不受影响。
只对云端接口生效 —— 接口地址是本机 / 内网（`127.0.0.1`、`localhost`、`192.168.*`、`10.*`、`172.16-31.*`）
时不受限制。

## 数据与隐私

- 全部数据都在本机 `data/`：角色卡、会话、设置（含 API Key）、资料库与向量缓存
- **没有任何遥测**，不联账号，只联系你自己填的接口地址
- 设置页的「导出备份」**不含 API Key**（Key 属于设备，不跟着数据跑）

### 数据目录

优先级：环境变量 `WORKBENCH_DATA_DIR` > 项目根目录的 `data-dir.txt` > 默认 `./data`。

`data-dir.txt` 里写一行纯路径即可（`#` 开头会被忽略），用来把数据放到同步盘：

```
/home/you/workbench-sync          # Linux / macOS
D:\workbench-sync                 # Windows
/storage/emulated/0/workbench-sync # 安卓
```

> ⚠ 别把项目放在只读目录里跑（会写 `data/`、`.tts-cache/`、向量缓存）；
> 只读位置请用 `WORKBENCH_DATA_DIR` 把数据指到可写目录。

### 导出 / 导入 / 多设备同步

- **导出备份**：一个 JSON，含全部角色和会话
- **导入合并**：按修改时间自动合并，两边记录都保留，不会互相覆盖
- **Syncthing**：让两台设备的 `data-dir.txt` 指向同一个同步目录即可；
  工作台会自动维护 `.stignore` 把 API Key 排除在同步之外

## 局域网访问与端口

```bash
node start.js                # 5178，只监听 127.0.0.1（安全默认）
node start.js 5179           # 换端口
node start.js 5178 0.0.0.0   # 监听全部网卡（手机可连）
node start.js 5178 192.168.1.5  # 只绑某一张网卡（暴露面更小）
WORKBENCH_HOST=192.168.1.5 node start.js   # 同上，用环境变量
```

`share.js` 能把打包好的 zip 临时通过局域网发给手机下载：

```bash
node share.js                                   # 共享 ../local-ai-workbench-v<版本>.zip
node share.js 8138 /path/to/some.zip            # 指定端口和文件
```

## 打包与自检

```bash
bash build.sh                 # 开发包（含 smoke.js 自检）
bash build.sh --release       # 发行包：去掉测试文件
powershell -File build.ps1 -Release   # Windows 上的等价命令
```

都会在项目**上一级**目录生成 `local-ai-workbench-v<版本>.zip`（开发包带 `-dev` 后缀），并自检：

- 条目名无反斜杠（否则安卓 unzip 建不出目录）
- 没有 `data/`（绝不把 API Key 打进包）
- 没有 `runtime/`（便携 Node 不进包）
- 发行包里不含 `smoke.js`

自检：`node smoke.js`（需要开发包；跑完自动清理临时数据目录）。

## 命令行与环境变量

| 变量 | 作用 |
| --- | --- |
| `PORT` | 端口，等价于第一个命令行参数 |
| `WORKBENCH_HOST` | 监听地址，等价于第二个命令行参数 |
| `WORKBENCH_DATA_DIR` | 数据目录，优先级最高 |
| `OLLAMA_EXE` / `OLLAMA_MODELS` | Ollama 可执行文件 / 模型目录（自动探测不到时手动指定） |
| `NODE_VERSION` / `NODE_MIRROR` | 便携 Node 的版本与下载源（默认官方源，失败自动换国内镜像） |

## 常见问题

**没装 Node / 提示找不到 node**
Linux：`bash linux/get-node.sh`；Windows：跑一次 `windows\start.cmd` 会自动下载便携版。

**端口被占用 / 没权限（EACCES）**
换一个端口。`EACCES` 常见于 1024 以下的端口，或 Windows 把该端口划进了 Hyper-V / WSL 的保留段
（用 `netsh interface ipv4 show excludedportrange protocol=tcp` 查看）。

**手机打不开电脑上的页面**
确认启动时用了 `0.0.0.0`、手机和电脑在同一个 Wi-Fi、电脑防火墙放行该端口。

**本地模型看不到 / 提示 model not found**
确认 Ollama 在跑，且启动它时带了正确的 `OLLAMA_MODELS`；必要时设 `OLLAMA_EXE` / `OLLAMA_MODELS`。

**模型一直「思考」很久**
Qwen3 这类勾上设置里的「关掉思考」。

**必应总给国内版**
选国际版就必须走代理（设置里的代理地址），否则会被按出口 IP 重定向。

**升级后数据还在吗**
在。升级只替换程序文件，`data/`（或你在 `data-dir.txt` 里指到的地方）不受影响。
